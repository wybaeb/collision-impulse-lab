# Импульс — тренажёр столкновений

Статический сайт для GitHub Pages. Всё приложение находится в `dist/index.html`.

## Публикация в GitHub Pages

В настройках репозитория откройте **Pages** → **Deploy from a branch** → выберите ветку `main` (или `master`) и каталог `/dist`.

Конфигурации хранятся локально в браузере. «Сохранить» также копирует JSON модели в буфер обмена.
